Settled platform rules:

- One currency in integer hundredths; preserve existing balances; grant every new account **250 credits**. Generated/registered creation paths have equal capability. Placeholder contacts must never enter provider delivery.
- Creator auto-seated/funded, ordinary participant rights, free pre-start seat movement. One active participation across all seven games. Public lists include waiting/playing tables, including full ones; completed/cancelled tables leave open discovery while ticket history and authorized direct links remain available (owner decision, 2 November). Private creator codes are 6–32 alphanumeric characters and grant details/seat access, not a seat or spectator gameplay.
- Per player: fee **0.90** plus contribution **1/5/15/30**. Seat/ticket/hold/account slot commit atomically. All funded players press the existing ready button; no fake start without an adapter.
- Pre-start withdrawal releases that participant's entire reservation. Started zero-gameplay cancellation refunds the whole match, including fees. Any accepted gameplay permanently blocks cancellation, including across rounds/restarts. Next deal is a non-gameplay control and never clears this marker.
- Explicit forfeit loses for the individual/whole partnership, with normal opposing-side winnings. No substitutions. Draw returns contributions and retains original fees. Trusted technical void for a confirmed qualifying incident returns contributions and fees; no public void writer.
- Disconnect, browser closure, logout and navigation preserve participants/funds/state indefinitely. No game, table, abandonment or disconnect deadlines. Transport repair intervals are not game clocks.
- Append-only official results and idempotent initial settlement are separate. Paid-result corrections remain unimplemented and require their own authorized revision/adjustment design.
